# Обновление учётной записи видео-сервера Timeweb

## Где работает функция загрузки
Функция загрузки на Timeweb работает в Lovable Cloud — во встроенном сервере этого проекта, через который выкладываются все серверные функции проекта. Внешнего или собственного сервера для неё нет. Логин и пароль она читает из секретов проекта `FILEBROWSER_USERNAME` и `FILEBROWSER_PASSWORD` (оба уже заведены).

## Где обновить секреты (действие пользователя)
Отдельной формы для замены уже сохранённого секрета у меня нет. Секреты меняются в редакторе проекта на lovable.dev:
- Компьютер: панель над предпросмотром → **More** (Ещё) → группа **Settings** → **Secrets**.
- Телефон: режим Chat → кнопка «...» внизу справа → **More** → нижнее меню разделов → **Settings** → **Secrets**.
- Если в группе Settings нет пункта Secrets, у учётной записи нет прав на изменение настроек проекта. Тогда секреты может обновить владелец или администратор рабочего пространства.

В разделе Secrets:
1. Найти `FILEBROWSER_USERNAME` → заменить значение на `lovable-uploader`.
2. Найти `FILEBROWSER_PASSWORD` → вписать пароль этой учётной записи.
Сохранённые значения там не показываются. Новые значения функция получит автоматически, повторно выкладывать её не нужно.

## Что сделаю после слова «готово»
1. Проверю вход служебной учётной записи на сервер (без вывода секретов).
2. В предпросмотре загружу через окно видеогалереи маленькое тестовое видео в Timeweb, проверю, что файл появился в /v и воспроизводится.
3. Удалю тестовый файл. Продакшен, опубликованные статьи и код не меняются.
