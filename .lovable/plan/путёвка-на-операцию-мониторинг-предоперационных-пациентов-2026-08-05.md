# Путёвка на операцию + мониторинг предоперационных пациентов

## 1. Кнопка в протоколе осмотра

В шапке протокола (рядом с «Заполнить стандарт») — кнопка **«Выдать путёвку на операцию»**.
Открывается диалог, поля предзаполняются из текущего протокола и карты пациента:

- ФИО, дата рождения, возраст (из визита);
- диагноз / заключение — кнопка «Взять из протокола» (диагноз, заключение, рекомендации);
- название операции (автодополнение из каталога операций, свободный ввод);
- срок операции: календарь с листанием месяцев, режим «одна дата» или «интервал дат»;
- перечень обследований — чек-лист (галочки), можно добавить своё обследование;
- памятка пациенту — текст из редактируемого шаблона;
- контакт координатора: **+7 903 005-61-11, Надежда Александровна** и инструкция переслать первый лист путёвки в Telegram / WhatsApp / MAX.

## 2. Печатный документ (3 листа)

1. **Лист 1 — путёвка**: ФИО, д.р., возраст, диагноз, операция, ориентировочная дата/интервал, QR-код на страницу отслеживания, блок координатора и инструкция по пересылке.
2. **Лист 2 — перечень обследований**: таблица с квадратиками для галочек, срок годности анализа, отметка «сдано».
3. **Лист 3 — памятка пациенту**: редактируемый в админке текст.

Каждый лист — с принудительным разрывом страницы, как согласие.

## 3. Редактирование в админке

Раздел «Путёвки на операцию» в админ-панели:
- редактор текста памятки (rich-text, версии);
- редактор справочника обследований (название, комментарий, срок годности, включать по умолчанию);
- контакты координатора.

## 4. Мониторинг (выбран максимальный вариант)

**Статусы путёвки:** выдана → анализы сдаются → анализы готовы → дата назначена → госпитализирован → оперирован; отдельно: перенесена, отказ, **потерян из виду** (нет активности N дней).

- **Дашборд «Предоперационные пациенты»** в админке: колонки по статусам, светофор просрочки (14 / 30 / 60 дней без движения), фильтры по врачу и дате операции, быстрые действия «позвонил», «перенести», «отказ» с комментарием.
- **Публичная страница пациента** по хэш-ссылке/QR из путёвки: список обследований с галочками, дата операции, памятка, кнопка «я сдал анализы», загрузка фото результатов.
- **Telegram-бот пациенту:** подписка по ссылке/QR из путёвки (deep-link с кодом путёвки), напоминания: через 3 дня («получили путёвку — начните обследование»), 10 дней, 21 день, за 7 и за 1 день до операции; кнопки «анализы сдал», «нужно перенести», «отказываюсь». Ответы падают в дашборд.
- **Сводка координатору** (Надежда Александровна) в Telegram раз в день: кто просрочил анализы, у кого дата на подходе, кто пропал более 30 дней; плюс мгновенное уведомление при отказе/переносе.
- **E-mail напоминания** — тот же график, для пациентов без Telegram (через существующую очередь писем).

## 5. Технические детали

- Таблицы: `surgery_referrals` (путёвка, статус, даты, диагноз, операция, публичный хэш, telegram_chat_id), `surgery_referral_items` (обследования путёвки + отметки), `surgery_referral_events` (журнал статусов и контактов), `surgery_exam_catalog` (справочник обследований), `surgery_memo_templates` (памятка). RLS: admin/editor — полный доступ, публичный доступ только через RPC по хэшу.
- Edge-функции: `surgery-referral-notify` (крон, напоминания пациентам и сводка координатору), `surgery-referral-bot` (webhook Telegram-бота, verify_jwt = false).
- Крон через pg_cron раз в сутки.
- Печать — по образцу `ProtocolPrintLayout` с разрывами страниц.

## 6. Что нужно от вас

Таблица предоперационных обследований (файл или текст) — внесу её в справочник как стартовый набор.
Для бота пациентам понадобится Telegram-бот (можно использовать существующий токен уведомлений).
