# Дублирование карусели отзывов на страницу «Отзывы и рейтинги»

## Что делаем
Карусель отзывов пациентов (компонент `ReviewsSection`, который уже работает на главной) показываем также на странице `/reviews` во вкладке «Отзывы пациентов» — под блоком плиток платформ.

## Объём изменений
Изменяется **только один файл**: `src/pages/Reviews.tsx`

1. Добавить импорт: `import ReviewsSection from "@/components/ReviewsSection";`
2. Вставить `<ReviewsSection />` внутри `<TabsContent value="patients">` — после блока «Читать отзывы на платформах», перед закрытием `TabsContent`.

Больше ничего: сам `ReviewsSection.tsx` не трогаем, главная страница не меняется, данные, маршруты, API, i18n, стили не меняются. Зависимости не добавляются.

## Почему это безопасно
- `ReviewsSection` — самодостаточный компонент: локальный `useState`, статический массив отзывов, никаких запросов к бэкенду.
- Он уже отрендерен на главной, значит на `/reviews` работать будет так же; поломать главную нельзя, потому что файл компонента не меняется.
- Откат = удаление двух добавленных строк.

## Нюанс, о котором стоит знать
`ReviewsSection` содержит свой заголовок («Отзывы пациентов»), блок цифр (отзывы/рекомендуют/42 года) и кнопки «Читать на Яндексе / ПроДокторов / DocDoc». На `/reviews` похожие цифры и ссылки уже есть — будет визуальное дублирование.

Варианты:
- **A (по умолчанию):** вставить как есть — минимальный diff, дублирование блоков остаётся.
- **B:** добавить в `ReviewsSection` необязательный prop (например `compact`), скрывающий заголовок, цифры и CTA. Тогда меняются два файла: `Reviews.tsx` и `ReviewsSection.tsx` — нужно ваше отдельное разрешение.
