# Шторка 18+ для клинических галерей

## Идея
Шторка живёт внутри самого компонента галереи (`ImageGallery`), поэтому она автоматически появится везде, где галереи уже используются: статьи для родителей, разделы для врачей, научные обзоры, лендинги материалов. Никаких правок в страницах не потребуется.

Флаг «закрыть шторкой» хранится там же, где уже хранится `cols=N` — служебной записью в маркере галереи. То есть у каждой галереи свой независимый флаг: медицинские схемы остаются открытыми, клинические фото — под шторкой.

## Как это выглядит для пользователя
1. Галерея рендерится как обычно (та же сетка, те же размеры — ничего не «прыгает»).
2. Поверх сетки — полупрозрачный слой: сами изображения размыты сильным блюром (угадываются силуэты), сверху затемнение и текст предупреждения.
3. Текст (в точности как заказано): заголовок «КЛИНИЧЕСКИЕ ИЗОБРАЖЕНИЯ · 18+», четыре абзаца обоснования (медицинские/научные цели, примечание 2 к ст. 242.1 УК РФ, условие подтверждения совершеннолетия), строка согласия, кнопка «Открыть клиническую галерею», внизу мелким шрифтом «Правовые основания: …».
4. По клику шторка исчезает с плавным раскрытием (fade + снятие блюра), галерея становится интерактивной (лайтбокс, аннотации).

## Разные размеры и наполнение
- Шторка — абсолютный слой над всей сеткой (`position: absolute; inset: 0`), значит подходит к любому числу фото и любому `cols=N`.
- Блюр делается на слое-обёртке сетки (`filter: blur(28px) + scale(1.03)`), а не на отдельных картинках — работает одинаково для 1 фото и для 20.
- Текст шторки адаптивный: на маленьких галереях (низкая высота слоя) показывается сокращённый режим — заголовок + строка согласия + кнопка, полный юридический текст раскрывается по ссылке «Подробнее». Определяем по измеренной высоте контейнера, а не по числу фото.
- Слой сам прокручивается, если текст не помещается (`overflow-auto`), чтобы кнопка всегда была доступна.

## Запоминание выбора
- Подтверждение сохраняется в существующую cookie `age_confirmed_18` (365 дней) — та же, что уже используется на `/results` и в `AgeConfirmationModal`. Подтвердив один раз, пользователь не увидит шторку на других страницах.
- Если cookie уже стоит — галерея открыта сразу, без шторки.
- Ничего не отправляется в базу, согласие только на клиенте.

## Админ: опция «Закрыть шторкой»
- В `PlaceholderGallery` (панель управления галереей для админа) рядом с существующим селектором «фото в ряд» добавляется переключатель **«Закрыть шторкой 18+»**.
- При включении в маркер галереи добавляется служебная запись `nsfw=1`, при выключении — убирается. Механика ровно та же, что у `cols=N`: запись пишется в контент статьи/обзора через уже готовые хелперы.
- По умолчанию выключено: схемы, рисунки, таблицы остаются открытыми. Админ включает шторку только на клинических фото.
- В админ-режиме сама шторка не мешает работе: показывается компактная плашка-индикатор «под шторкой 18+», редактирование и загрузка доступны как сейчас.

## Технические детали
- `src/lib/markdown/galleryMarkers.ts` — по образцу `GALLERY_COLS_ENTRY_RE`/`extractGalleryCols`/`withGalleryCols` добавляются `GALLERY_NSFW_ENTRY_RE`, `extractGalleryFlags` (возвращает `{ cols, nsfw, entries }`) и `withGalleryFlags`. Старые маркеры без флага читаются как `nsfw: false` — обратная совместимость полная.
- `src/components/gallery/ClinicalCurtain.tsx` — новый компонент: слой с текстом, кнопкой, cookie-логикой, измерением высоты для компактного режима. Все цвета — через семантические токены (`bg-background/80`, `text-foreground`, `border-border`, `text-destructive`), без хардкода.
- `src/components/parents/ImageGallery.tsx` — парсит `nsfw`, оборачивает сетку в контейнер с `relative`, применяет блюр-класс и рендерит `ClinicalCurtain`, пока не подтверждено. Пока шторка закрыта: клики по фото и открытие лайтбокса заблокированы (`pointer-events-none` на сетке).
- `src/components/parents/PlaceholderGallery.tsx` — переключатель `Switch` + запись флага в контент теми же функциями, что и `cols`.
- `src/lib/markdown/galleryMarkers.ts` уже фильтрует служебные записи от дедупликации — `nsfw=1` добавляется в тот же список исключений, чтобы не появлялись «пустые слоты».
- Экспорт в PDF/DOCX и печатные виды (`ReviewPrintView`) служебную запись игнорируют, шторка в печать не попадает.
- i18n: русский текст — основной; для английской локали добавляется перевод в `en.json` (тот же смысл, ссылка на российское право сохраняется как справка).
