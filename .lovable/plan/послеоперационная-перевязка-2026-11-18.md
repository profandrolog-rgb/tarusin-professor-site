# Послеоперационная перевязка

## Новый протокол
- Добавить «Послеоперационная перевязка» в существующий список консультаций, осмотров и обследований.
- Сохранить привычные дату визита, ФИО пациента из карточки, возраст на дату визита и печатный бланк.
- Добавить редактируемый номер перевязки — положительное целое число; номер указывает врач, без предположений о перевязках в других учреждениях.
- Подставлять название операции из существующей истории операций пациента тем же способом, что в послеоперационных осмотрах. При отсутствии сведений поле остаётся пустым, доступен ручной ввод. Заполненное название не перезаписывается.
- Поле «Жалобы» — свободный текст.
- «Соматический статус» — редактируемый текст с исходным заполнением: «Общее состояние удовлетворительное, кожные покровы обычной окраски, кардио-респираторная деятельность стабильна, живот при пальпации мягкий безболезненный во всех отделах. Физиологические отправления в норме».

## Локальный статус
Отдельные поля выбора, без автоматического утверждения состояния раны:
- Заживление: первичным / вторичным натяжением.
- Признаки воспаления: есть / нет.
- Признаки гематомы: есть / нет.
- Швы: состоятельны / не состоятельны.
- Отделяемое: нет / сукровичное / гнойное.

## Выполнено
Для каждого пункта — выбор варианта и отдельное свободное поле для дополнений:
- Санация области швов: перекись водорода 3% / водный раствор хлоргекседина 0,05%.
- Обработка области швов: спиртовой раствор йода 2% / йодопирон / бетадин / повидон-йод / спиртовой раствор бриллиантового зеленого 1%.
- Асептическая повязка: сухая / полуспиртовая / с мазью левомеколь / с мазью гидрокортизон 1% / с мазью «Тарумель».

Названия и концентрации сохраняются из задания; новые препараты и медицинские рекомендации не добавляются. Пустой выбор не означает выполненную манипуляцию.

## Заключение и рекомендации
- Редактируемое заключение с исходным текстом «Этап репарации после операции».
- Выбор рекомендации: «Повязку не снимать до следующего визита» / «Смена повязки ежедневно», с возможностью дополнить текст.
- Все заполненные разделы выводятся на отдельный бланк текущей перевязки, включая номер, операцию и свободные дополнения.

## «Нет повторного визита» во всех протоколах
- Добавить переключатель рядом с существующим календарём контрольного осмотра. Этот общий блок используется во всех консультациях, обследованиях и осмотрах, включая физиолечение и новую перевязку.
- При включении убрать обязательность даты, интервала и времени повторного приёма; очистить эти значения и скрыть их поля. Дата текущего визита остаётся без изменений.
- В печати показать «Повторный визит не назначен», без старой даты или длительности.
- При выключении вернуть существующий календарь и прежние требования к заполнению. Случайно очищенная дата сама не восстанавливается.
- Старые протоколы без этого переключателя продолжают работать как раньше.

## Технические ограничения
Проверено действующее ограничение типов визита: новый тип пока не разрешён. Нужна только замена этого ограничения с добавлением `postop_dressing`; все прежние значения сохраняются. Новые таблицы и колонки не создаются, существующие протоколы не переписываются. Изменение оформляется штатным инструментом базы, который создаёт файл изменения и обновляет типы автоматически.

Не менять зависимости, архитектуру, маршруты, доступ, Vite, сетевые настройки, резервные адреса, галереи, `ForParents.tsx`, `main.tsx`, `client.ts` и существующие лечебные назначения. Исходные `vite.config.ts` и `main.tsx` проверены: соответствуют зафиксированному варианту.

## Порядок внедрения и проверки
1. После согласования плана подготовить полный точный diff перечисленных изменений и показать его до применения, согласно вашему правилу точечных правок.
2. После «Подтверждаю» применить только согласованные изменения.
3. Проверить под вашим аккаунтом: создание перевязки, подстановку операции, пустую операцию при отсутствии сведений, ручное заполнение номера, выбор вариантов и свободного текста, сохранение и повторное открытие, предпросмотр и печать.
4. Проверить «Нет повторного визита» в перевязке, первичной и повторной консультации, УЗИ и физиолечении: сохранение, повторное открытие, печать без даты и снятие переключателя с возвратом обязательности заполнения.
5. Выполнить целевые тесты; убедиться, что существующий осмотр с датой/интервалом печатается без изменений.

Публикация не входит в этот запрос и выполняется только по отдельной команде.
