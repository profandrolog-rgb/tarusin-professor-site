# Исправление замечаний проверки

Уже не актуально (закрыто): протокол девочек сохраняется; адрес сервера api3 основной везде.

## Подтверждено проверкой
**3. Вопрос‑ответ пуст для посетителей** — в базе удалено правило, разрешающее всем читать опубликованные ответы. Вернуть правило: читать можно только записи с `is_published = true` (без email автора — колонки уже ограничены).

## Требуют правки кода (проверю каждое перед изменением, правлю минимально)
4. Страница заболевания «вечно грузится» при неверной ссылке — если ранняя загрузка не нашла статью, запускать обычную загрузку или показывать «не найдено».
5. «Править» на карточке заболевания может стереть текст — кнопка «Сохранить» недоступна, пока текст статьи не загрузился; при ошибке загрузки — не сохранять текст статьи.
6. Новые планы/шаблоны после сохранения показывают «есть несохранённые изменения» — заново снимать «точку сохранения» после перезагрузки записи и не учитывать служебные id строк.
7. RTF с русским текстом превращается в «????» — правильно расшифровывать `\uNNNN`.
8. Кадрированные фото в печати обзора не показываются — в печати обзора отрезать `@crop=...` от имени файла (как в остальных местах; сами маркеры галерей не трогаю).
9. Журнал операций: при «Изменить» сразу всплывают подсказки пациентов — не открывать подсказки, пока пользователь сам не изменил ФИО.
10. Кнопки галерей в предпросмотре откатывают несохранённый текст — брать за основу текст из редактора, а не из базы.
