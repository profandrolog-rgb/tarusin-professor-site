# Исправление открытия нового протокола

## Подтверждённое состояние

- Опубликованный `/admin/visits/new` отвечает HTTP 200 и уже содержит ожидаемую стартовую «крутилку».
- Скриншот консоли подтверждает прежние React #418 и #423 — несовпадение разметки при восстановлении страницы.
- Текущий `ClientOnlyGate` снимает «крутилку» через `useEffect`. При отложенном восстановлении страницы этот эффект может выполниться раньше, чем React закончит восстановление вложенного содержимого.

## Единственная правка

Изменить только `src/components/ClientOnlyGate.tsx`:

- убрать переключение `mounted` через `useState` + `useEffect`;
- использовать штатный для React механизм `useSyncExternalStore` с серверным значением `false` и клиентским значением `true`;
- внешний вид «крутилки», список служебных адресов и остальные файлы не менять.

Предлагаемый diff:

```diff
-import { ReactNode, useEffect, useState } from "react";
+import { ReactNode, useSyncExternalStore } from "react";
...
-  const [mounted, setMounted] = useState(false);
-  useEffect(() => setMounted(true), []);
+  const mounted = useSyncExternalStore(
+    () => () => undefined,
+    () => true,
+    () => false,
+  );
```

## Проверка до публикации

1. Открыть собранную версию сразу по `/admin/visits/new` с действующей сессией.
2. Убедиться, что форма нового протокола появилась, адрес не изменился и в консоли нет #418/#423.
3. Отдельно проверить переход из списка протоколов к созданию нового.
4. Проверить типы и текущий журнал сборки.
5. Не публиковать без отдельной команды.
