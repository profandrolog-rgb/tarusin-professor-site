## Пакет правок по протоколам визитов

Разбил ваш список на 12 пунктов. Предлагаю такой порядок и объём работ.

### 1. Библиотека назначений (чтобы не писать одно и то же)

Новая таблица `assignment_library` (категория: препарат / режим / диета / прочее, текст, счётчик использований, автор). При сохранении визита все новые формулировки из назначений автоматически попадают в библиотеку. В форме назначений — автодополнение и кнопка «Из библиотеки» с сортировкой по частоте использования.

### 2. Сбор всего, что вы дописывали руками

Скрипт пройдёт по всем существующим `patient_visits.protocol_data` и сравнит текст полей с шаблонами (`visit_text_templates`, `DEFAULT_PROTOCOL_DATA`). Всё, чего нет в шаблонах, выгружу в **таблицу (XLSX/CSV) с номерами** — колонки: № / тип протокола / поле / текст / сколько раз встречалось / предлагаемая категория. Вы скачаете, поправите, вернёте — я залью утверждённое в библиотеку и шаблоны.

### 3. Цитаты из ИИ-анализа по правому клику

Выделение текста в блоке ИИ-анализа → контекстное меню «Отправить в поле…» → выбор целевого поля протокола. Вставка **дописывается** в конец поля (с новой строкой), не затирая предыдущее. Можно отправлять сколько угодно фрагментов.

### 4. Опциональные УЗИ-блоки во всех протоколах

По образцу «УЗДГ органов МПС» добавляю три сворачиваемых опциональных блока: УЗИ почек, УЗИ мочевого пузыря, мочевой пузырь с остаточной мочой. Подключаются во всех протоколах, кроме `postop_day3` / `postop_day7`.

### 5. Подтягивание операции на повторный визит

При открытии повторного протокола у оперированного пациента название и дата операции автоматически заполняются из журнала операций (последняя запись), с возможностью поправить вручную. добавь еще наш выпадающий список операций - если вдруг на этого пациента в журнале операций нет записи

### 6. Таблица анализов и обследований в заключении

Спарсенные лабораторные и инструментальные результаты собираются в отдельную таблицу в конце заключения. Вывод — **опциональный** (галочка в форме).

### 7. Отдельный лист согласия + новый текст

Информированное согласие и новый текст «Мне, законному представителю пациента…» печатаются **всегда** в конце протокола, каждый — на отдельном листе (принудительный разрыв страницы), с полями для подписи.

### 8. «Заметки по визиту» — только для врача

Новое опциональное поле в каждом протоколе. **Категорически исключается из печати** — как уже сделано для «Рассуждений ИИ» (исключение в `ProtocolPrintLayout` + `KNOWN_KEYS`).

### 9. Микробиота по Осипову

Добавляю распознавание формата анализа микробиоты по Осипову в парсер PDF (маркеры-жирные кислоты, отдельная схема таблицы). Пришлите, пожалуйста, тот файл, на котором была ошибка, — прогоню на нём.

### 10. Динамика анализов между визитами

Если у пациента есть анализы с разных дат — в протоколе появляется блок сравнения: показатель / прошлое значение и дата / текущее / стрелка динамики. Вывод в печать — опциональный.

### 11. Асимметрия яичек и придатков

В УЗИ-блоке два отдельных поля: «Асимметрия яичек, %» и «Асимметрия придатков, %», с автоматическим расчётом от введённых объёмов (правое vs левое) и возможностью перебить вручную.

### 12. Технические детали

- Миграции: `assignment_library` (+GRANT, RLS для admin/editor), новые ключи в `protocol_data` (jsonb — миграция схемы не нужна).
- Затрагиваемые файлы: `ProtocolForm.tsx`, `ProtocolPrintLayout.tsx`, `sections/UziReproductive.tsx`, новые `sections/ExtraUziKidneys.tsx`, `sections/ExtraUziBladder.tsx`, `VisitNotesField.tsx`, `AssignmentsPanel.tsx`, `parse-medical-pdf`.
- Печать проверю визуально (PDF-рендер) перед сдачей.
