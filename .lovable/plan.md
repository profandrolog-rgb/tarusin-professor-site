# Специальный блок «Заметка профессора» в лонгридах

Врезка на чуть более сером фоне, шириной 2/3 страницы, рукописным курсивом — для клинических случаев и рассуждений по теме страницы.

## Как это будет выглядеть

- Блок шириной ~66% на десктопе, прижат вправо: левая треть остаётся пустой, заполненная часть занимает правые 2/3. На мобильном — 100% по ширине.
- Фон: `bg-muted/60` (чуть серее текста статьи), тонкая левая полоса акцентного цвета, скругление 12px как везде на сайте.
- Текст: рукописный курсив шрифтом **Caveat** (Google Fonts, кириллица) — тёплый, читаемый, не выбивается из типографики сайта. Размер чуть крупнее основного текста (1.05–1.15rem), увеличенный интерлиньяж.
- Необязательная иконка в левом верхнем углу блока + необязательный заголовок («Клинический случай», «Из практики» и т.п.).
- Внутри — полноценный форматированный текст: абзацы, жирный, курсив, списки, ссылки.

```text
┌────────────────────────────────────┐            ← 2/3 ширины
│ ⟡  Из практики                     │
│    Мальчик 14 лет, обратился с…    │  (курсив,
│    рукописный шрифт, серый фон)    │   Caveat)
└────────────────────────────────────┘
              ↑ пустое место, 1/3 ширины слева
```

## Как это будет работать в редакторе

В `ArticleMarkdownEditor` (он же используется в inline-редакторе страниц болезней) появится кнопка **«Специальный блок»**:

1. Клик — в место курсора вставляется пустой блок, курсор внутри. Можно сразу писать и форматировать обычными кнопками панели.
2. При наведении на блок — мини-панель управления: выбор иконки, поле заголовка, «Выше»/«Ниже» для перемещения, «Удалить».
3. Иконки: выпадающий список с превью из уже подключённого `lucide-react` (стартовый набор: стетоскоп, лампочка, цитата, сердце, микроскоп, предупреждение, звезда, книга; «без иконки» по умолчанию). Набор задан одним массивом — пополнить позже одной строкой.

## Техническая часть

- **Формат хранения:** внутри `article_content` блок живёт как HTML-элемент
  `<aside data-note data-icon="stethoscope" data-title="Из практики">…</aside>`.
  Это переживает и markdown-, и HTML-статьи: рендер уже идёт через `rehypeRaw`, галереи-маркеры не затрагиваются.
- **Tiptap:** новый кастомный узел `ProfessorNote` (`src/components/parents/tiptap/ProfessorNoteNode.tsx`) — блочный узел с `content: "block+"`, NodeView с панелькой управления, `parseHTML`/`renderHTML` по `aside[data-note]`.
- **Turndown:** правило `keep` для `aside[data-note]`, чтобы при конвертации в markdown блок сохранялся как HTML без экранирования (по аналогии с существующим правилом для галерей).
- **Публичный рендер:** класс `.professor-note` в `src/index.css` (светлая и тёмная темы) + шрифт Caveat через `index.html`; `MarkdownArticle` и `HtmlArticle` рендерят блок как есть, иконка подставляется маленьким скриптом-компонентом по `data-icon`.
- **Безопасность:** в `DOMPurify.sanitize` разрешить `aside` и атрибуты `data-note`, `data-icon`, `data-title`.
- **Печать/PDF:** блок печатается без обрезки, фон сохраняется (`print-color-adjust: exact`).
